# 💰 理財 × 無蝦米 打字練習

看理財知識卡 → 切換到無蝦米輸入法 → 照著打出同樣的中文，同時學理財＋練拆字手感。

## ▶️ 直接玩（免安裝）

**👉 https://woodychenlawa.github.io/finance-boshiamy-typing/**

點開就能玩，手機、電腦都可以。

## 玩法

1. 選分類：基礎名詞 / 儲蓄預算 / 投資入門，共 30 題
2. 看左邊知識卡（名詞＋白話解釋＋為什麼重要）
3. 把輸入法切到【無蝦米】，照著深色框的句子打出來
4. 綠字＝對、紅字＝錯，即時顯示速度、正確率，80 分過關自動存進度
5. 熟了可勾「遮住對照」當測驗用

## 本機使用

直接雙擊 `finance-boshiamy-typing.html`（或 `index.html`，內容相同）用瀏覽器開啟即可，進度存在瀏覽器 localStorage。
